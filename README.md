# 🐉 Кибер-Дракон Кликер

Мобильная кликер-игра про битву с мифическим боссом.

## 🎮 Как играть
- Нажимай кнопку **«Ударить ⚔️»**, чтобы наносить урон дракону.
- Иногда случаются критические удары (**CRIT!**) с усиленным уроном и анимацией.
- Кнопка **«Лечить 🧪»** восстанавливает здоровье босса.
- Игра отлично работает прямо с телефона!
